// Description

SYNAPSE.HUB is a multi-game Roblox script hub built around a WindUI interface. It combines universal combat, visual, movement, world, optimization, and utility features with 18 dedicated game modules. Each supported game gets its own feature set, while shared systems such as Player Radar, Object Radar, Advanced Aim, and movement utilities are reused across multiple modules.

Overall, SYNAPSE.HUB is an 18-game multi-purpose Roblox hub with universal combat/movement/visual tools plus dedicated modules for each supported experience, with Steal An Egg being the most progression/automation-heavy module and the competitive modules focusing more heavily on combat assistance, radar, targeting, and game-specific utilities.
